# Monorepo Ecommerce App

A fullstack ecommerce monorepo built with Next.js, Turborepo, Zustand, and Tailwind CSS.

## Live Demo

### Client App
https://monorepo-ecommerce-app-client.vercel.app

### Admin Dashboard
https://monorepo-ecommerce-app-admin.vercel.app

---

## Tech Stack

- Next.js
- Turborepo
- TypeScript
- Tailwind CSS
- Zustand
- Framer Motion
- Vercel

---

## Apps

### Client App

Features:
- Product listing
- Product details
- Add to cart
- Checkout flow
- Success page
- Responsive UI

### Admin Dashboard

Features:
- Dashboard layout
- Sidebar navigation
- Product management UI
- Responsive admin panel

---

## Monorepo Structure

```bash
apps/
  admin/
  client/

packages/
```

---

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run development server:

```bash
pnpm dev
```

Build project:

```bash
pnpm build
```
